# Clyde B. Jones Funeral Home website (design preview)

The new website for Clyde B. Jones Funeral Home Co. Ltd., Top Rock, Christ Church, Barbados. It is built by Tech Nova Barbados.

**This repo is public.** It holds only the website. Client notes, the proposal and prices are kept in Tech Nova's private repo.

- Plain HTML and CSS. No framework and no server.
- Hosted free on GitHub Pages as a preview, so the client can see the design.
- The page shows a "Design preview" note, and tells Google not to list it (`noindex` and `robots.txt`).

## Look at it on your laptop

From this folder:

```
npx serve .
```

Then open the address it prints.

## Status
- The first screen of the homepage follows the concept: top bar, menu, hero with tribute search, the three "help now" cards, sample tribute cards, footer, and the Call bar on phones.
- The other homepage sections are marked "To design".
- Tribute names are samples only.
